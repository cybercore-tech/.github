# .github

Default community health files for every [Cybercore Tech](https://cybercoretech.net/) repository. GitHub shows these on any repo that doesn't have its own copy.

| File | What it's for |
|---|---|
| [`SECURITY.md`](SECURITY.md) | Report vulnerabilities to security@cybercoretech.net |
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | Contributor Covenant 2.0; enforcement contact dev@cybercoretech.net |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | Issues, pull requests, how to get in touch |
| [`FUNDING.yml`](FUNDING.yml) | The Sponsor button → [Buy Me a Coffee](https://buymeacoffee.com/cybercoretech) |

The contact details match the shared source of truth on the org site, [`data/contact.json`](https://github.com/cybercore-tech/cybercore-tech.github.io/blob/main/data/contact.json).
