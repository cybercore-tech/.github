# Security policy

This policy covers every Cybercore Tech repository that doesn't ship its own `SECURITY.md`. Projects that do have one describe their threat model there. The reporting address is the same everywhere.

## Reporting a vulnerability

Email **[security@cybercoretech.net](mailto:security@cybercoretech.net)**. Include:

- the affected repository, plus the file or commit, and a minimal repro or PoC
- what you'd expect to happen instead
- how you'd rate the impact (your best guess is fine)

Expect an acknowledgement within a few days. Please don't include exploit details in a public GitHub issue, pull request or discussion until a fix has shipped.

## Supported versions

Unless a project says otherwise, only the latest commit on its default branch is supported.

## Everything else

General questions: [dev@cybercoretech.net](mailto:dev@cybercoretech.net).
